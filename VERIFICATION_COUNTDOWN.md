# Countdown verification

Date: 2026-09-04

The browser flow was verified locally as fullscreen landing or window fallback → rules → player setup → Start challenge → black full-viewport countdown overlay. The overlay displayed `GET READY`, a visible `2` during the check, and then disappeared after the 3-2-1-GO sequence. The live game appeared only after the overlay completed, and the timer was running at approximately 22.5 seconds remaining, confirming the countdown time is not deducted from the 30-second round. The target color and board rendered correctly after GO.
